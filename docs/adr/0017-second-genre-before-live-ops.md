# ADR 0017: Second genre before live-ops

Status: accepted

## Context
The strongest proof that the packages are generic is another game built on them.

## Decision
Block Puzzle (block placement) was built before the live event (a race, removed 22 Oct), and Blast (tap-to-blast) after it, each on the same packages.

## Consequences
- The packages were tested by two very different rule sets.
- Live-ops arrived later in the plan.

## Alternatives considered
- Live-ops first: a single game proves little about reuse.
