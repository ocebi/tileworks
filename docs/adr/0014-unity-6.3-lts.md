# ADR 0014: Unity 6.3 LTS

Status: accepted

## Context
The project should run on a supported engine with current tooling.

## Decision
Unity 6.3 LTS (6000.3.26f1), URP, Input System only.

## Consequences
- Long-term support; current build and profiling tools.
- Some packages lag behind (ZString was dropped, see the decisions log).

## Alternatives considered
- Unity 2022 LTS: older tooling, shorter remaining support.
