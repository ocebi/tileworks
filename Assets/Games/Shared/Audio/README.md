# Shared audio

- `sfx_*.wav` are generated by `Tools/audio/make_sfx.py` (`python3 -I Tools/audio/make_sfx.py Assets/Games/Shared/Audio`).
  Edit the script, not the files.
- `Music/` holds CC0 tracks by MintoDog from OpenGameArt:
  - `music_home`: Cozy Puzzle Title (https://opengameart.org/content/cozy-puzzle-title)
  - `music_game_1`: Cozy Puzzle In-Game 3 (https://opengameart.org/content/cozy-puzzle-in-game-3)
  - `music_game_2`: Cozy Puzzle In-Game 2 (https://opengameart.org/content/cozy-puzzle-in-game-2)
  - `music_hard`: Magic Puzzle In-Game 2 (https://opengameart.org/content/magic-puzzle-in-game-2)
  - `music_clear`, `music_fail`: Cozy Puzzle Jingle & Result (https://opengameart.org/content/cozy-puzzle-jingle-result)
- `explosion_synth.mp3`: Synthesized Explosion by qubodup, CC0 (https://opengameart.org/content/synthesized-explosion). The bomb sound.
- The other effects come from Kenney's CC0 packs (Impact, Digital, Sci-fi, Casino and Interface sounds) and live in
  `Assets/ThirdParty/Kenney/Audio/`.
- Import settings come from `AudioImportRules` (Games/Shared/Editor).
